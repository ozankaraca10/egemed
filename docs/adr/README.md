# Mimari karar kayıtları (ADR)

Bu dizin EGEMED CLIX mimari kararlarının taslaklarını barındırır. Taslaklar
insan onayına sunulur; öneri metni karar değildir.

| ADR | Konu | Durum |
|---|---|---|
| [ADR-001](001-monorepo.md) | Monorepo | Önerildi |
| [ADR-002](002-yigin.md) | Yığın (kabuk ve API) | Önerildi |
| [ADR-003](003-gomme.md) | Simülatör gömme modeli | Önerildi |
| [ADR-004](004-lrs.md) | LRS ve xAPI ifade iletimi | Önerildi |
| [ADR-005](005-kimlik.md) | Kimlik ve öğrenci tanımlayıcısı | Önerildi |

`Durum: Kabul` satırını yalnız insan yazar. Astra ikinci görüşü her ADR'de
`Bekleniyor.` olarak durur; bulgular gelene kadar karar kaydı tamamlanmış
sayılmaz.
